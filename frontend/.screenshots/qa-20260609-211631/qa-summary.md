## 发现问题

### ISSUE-001 — 移动端水平溢出 (中等，预存)
- **影响**: 所有页面的 `header.glass-nav` 在 375px 视口下产生 199px 水平溢出
- **原因**: 导航栏元素（Logo 文字 + 搜索框 256px + 桌面导航链接）固定宽度总和超过视口
- **状态**: 预存问题，非本次修改引入

### ISSUE-002 — ECharts CSS 渲染警告 (低，框架级)
- **影响**: `/stock/000001` 页面有 4 个 console.error 来自 ECharts/React CSS shorthand 冲突
- **原因**: ECharts 渲染时混合使用 border shorthand 和 longhand 属性
- **状态**: 框架级噪音，不影响功能
